# Foundly downloads

Official Apple Silicon beta downloads for Foundly.

Install the latest DMG from [Releases](https://github.com/Openpod/foundly-releases/releases). Move Foundly to Applications. Updater-enabled builds download future published versions inside the app and offer Restart to update.

Beta builds currently use Apple Development signing and are not notarized. macOS may require Open Anyway on first install.

This repository contains app downloads and update metadata. The development repository is maintained separately.
